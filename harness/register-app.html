GitHub App для харнесса

Приложения GitHub создаются только через браузер — API для этого нет. Форма собирает манифест с нужными правами и событиями, GitHub генерирует App ID, приватный ключ и секрет вебхука сам.

Приложение, созданное в одной организации, ставится только в неё. Если контур обслуживает репозитории двух организаций — приложений нужно два. Именно на это натыкаются, пытаясь переиспользовать чужой App.

Дальше

  1. На странице GitHub нажать Create GitHub App.
  2. GitHub перебросит на <адрес>/issue/webhook?code=…. Страница покажет ошибку — так и должно быть: вебхук браузеру не отвечает.
  3. Скопировать code из адресной строки и выполнить: 
    bash finish-registration.sh <code>
    Скрипт обменяет код на учётные данные и запишет harness-app.env — три строки для Environment в Dokploy. Приватный ключ никуда не уходит, только в этот локальный файл.
  4. На странице приложения — Install App и выбрать организацию.

Код одноразовый и живёт около часа. Просрочили — создавайте приложение заново, это дешевле, чем чинить.
